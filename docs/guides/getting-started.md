# Getting Started Guide

Welcome to Roshan Beats! This guide will help you get started with importing music, creating playlists, and enjoying your music library.

## First Time Setup

### 1. Import Your Music
- Click the **Import** button (or floating action button)
- Select audio files from your device
- Supported formats: MP3, WAV, OGG, AAC
- Files are processed and added to your library

### 2. Explore Your Library
- Browse songs in grid or list view
- Use the search bar to find specific tracks
- Filter by genre, artist, or album
- Sort by title, artist, or date added

### 3. Create Your First Playlist
- Go to the **Playlists** tab
- Click **Create Playlist**
- Give it a name and description
- Add songs by clicking the menu button on songs

## Basic Playback

### Playing Music
- Click any song in your library
- Use the mini-player at the bottom
- Expand to full player for more controls

### Player Controls
- **Play/Pause**: Spacebar or play button
- **Next/Previous**: Arrow keys or buttons
- **Volume**: Slider or up/down keys
- **Seek**: Click progress bar or use arrow keys

### Voice Commands
- Say "Play [song name]" to start playing
- "Pause", "Stop", "Next", "Previous"
- "Volume up/down", "Shuffle on/off"

## Advanced Features

### Equalizer
- Access EQ in the full player
- Choose presets: Flat, Rock, Pop, Jazz, Classical
- Or customize the 5 frequency bands

### Offline Listening
- Songs are automatically cached when played
- Available offline in the **Offline** section
- Manage cache in settings

### Playlist Management
- Drag and drop to reorder songs
- Edit playlist details
- Share playlists (coming soon)

## Settings & Preferences

### Audio Settings
- Default volume and playback rate
- EQ preset selection
- Gapless playback toggle

### Interface Settings
- Theme selection (Light/Dark)
- Grid vs List view default
- Animation preferences

### Storage Settings
- Cache management
- Import history
- Data export/import

## Troubleshooting

### Import Issues
- Check file formats are supported
- Ensure files aren't corrupted
- Try smaller batches for large libraries

### Playback Issues
- Check browser audio permissions
- Try refreshing the page
- Clear cache if audio is distorted

### Performance Issues
- Reduce library size
- Clear old cache files
- Use list view for large libraries

## Tips & Tricks

- Use keyboard shortcuts for faster navigation
- Create playlists for different moods
- Enable gapless playback for albums
- Use voice commands hands-free
- Regular backups of your library
